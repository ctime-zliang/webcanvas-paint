# WebCanvas-Paint / lib-section 设计文档

## 1. 项目概述

**webcanvas-kit** 是一个基于 WebGL 的 2D 矢量图形绘制引擎库，提供了完整的画布绑定、图形编辑、坐标变换、撤销重做和图元管理能力。项目使用 TypeScript 编写，构建工具为 esbuild，目标 ES2016。

### 1.1 核心定位

| 维度 | 描述 |
|------|------|
| 渲染后端 | WebGL 1.0（含 WebGPU 预研备份） |
| 场景维度 | 2D 优先，保留 3D 扩展接口 |
| 图元种类 | Line / Arc / Circle / Point / Rect / Image / Text |
| 交互形式 | 指针输入 → 工具链 → 绘制/选取/变换 |
| 导出能力 | Canvas → SVG 转换（worker 离线） |

### 2.1 分层说明

| 层 | 目录 | 职责 |
|----|------|------|
| **Controller** | `src/controller/` | 业务逻辑控制器：元素管理、图层管理、画布状态、选区、滤镜 |
| **Service** | `src/service/` | 资源服务：RTree 空间索引服务、字体服务、图片资源服务 |
| **Manager** | `src/manager/` | 全局管理器：事件总线、贴图源管理、文本图形管理、Worker 管理 |
| **Tool** | `src/tool/` | 交互工具链：绘制工具、选择工具、辅助工具、拖拽工具、帧工具、历史记录 |

| **Engine** | `src/engine/` | 底层渲染引擎：WebGL 封装、着色器程序、缓冲区管理、数学库、算法库 |

## 3. 核心模块设计

### 3.1 入口类 WebCanvas

```typescript
class WebCanvas {
    constructor(canvasElement: HTMLCanvasElement)
    async init(): Promise<boolean>
    quit(): void
    // 公共 API
    get messageTool(): MessageTool
    get drawLayerController(): DrawLayerController
    get d2ElementController(): D2ElementController
    get canvasController(): CanvasController
    get operationController(): OperationController
}
```

**生命周期**：
1. `new WebCanvas(canvas)` → 调用 `createConstant()` 初始化全局依赖
2. `init()` → CoreInit(引擎检测) → ViewInit(视图初始化) → EnvirInit(环境同步) → LayerInit(图层初始化) → D2ToolInit(工具链绑定)
3. `quit()` → 取消 rAF → 销毁工具 → `destoryConstant()` 逐一释放资源

### 3.2 全局依赖容器 Constant

采用**非注入、非容器**的轻量设计：全局导出对象 `Constant`，在 `createConstant()` 中统一 new 实例并赋值，在 `destoryConstant()` 中逐一调用 `quit()` 并置 `undefined`。

Manager 层使用**单例模式** (`getInstance()` / `quit()`)，Controller 层使用**普通实例**挂载到 Constant。

### 3.3 渲染引擎 (Engine)

#### 3.3.1 渲染管线

```
Camera (投影 + 视图矩阵)
    │
    ▼
Scene (场景管理，控制 Plane 对象)
    │
    ▼
Renderer (canvas/GL 上下文持有)
    │
    ▼
WebGL (缓冲区创建 / 着色器编译 / 纹理管理 / 帧缓冲)
    │
    ▼
PlaneGL → PrimitiveGL → ProgramGL / InstancedProgramGL
```

#### 3.3.2 Camera 系统

- **投影类型**：正射投影 (ORTH) / 透视投影 (PERS)
- **核心参数**：lookForEyePosition, lookForAtPosition, scaleRatio
- **矩阵输出**：`getViewMatrix4()` = LookAt × Projection × Scale
- **坐标变换**：DOM像素坐标 ↔ 场景物理坐标 双向转换

#### 3.3.3 WebGL 渲染器

- 2D 模式：关闭深度测试、面剔除，启用 Alpha 混合
- 帧缓冲栈：支持嵌套离屏渲染
- Instanced 渲染：通过 `ANGLE_instanced_arrays` 扩展实现批量实例化

### 3.4 交互工具链 (Tool)

```
EventsLoader (DOM事件监听)
    │
    ▼
D2FrameTool (帧工具：平移/缩放/旋转画布)
    │
    ▼
ToolChain (工具链路由)
    ├── DrawD2ToolManager (绘制工具管理)
    ├── BaseSelectionTool (选取工具)
    ├── BaseAuxiliary (辅助工具)
    └── DropDragTool (拖拽工具)
```

- **事件驱动**：指针事件 → InputInfo → MessageBus 发布
- **命令模式**：`EDrawD2ToolCommand` 枚举切换当前绘制工具
- **历史记录**：`HistoryManager` + Command 模式实现 Undo/Redo

### 3.5 对象模型 (Objects)

采用 **Model-Shape 分离** 设计：

| 层 | 职责 | 单例管理器 |
|----|------|-----------|
| Model | 图元数据(坐标/样式/ID等) | D2LineModelManager, D2ArcModelManager... |
| Shape | 渲染数据(顶点/缓冲/WebGL资源) | D2LineShapeManager, D2ArcShapeManager... |
| Assist | 辅助图形(选框/控制点) | Assist Manager |

支持的 2D 图元：
- **Line** - 线段
- **Arc** - 圆弧
- **Circle** - 圆
- **Point** - 点标记
- **Rect** - 矩形
- **Image** - 图片
- **Text** - 文本

### 3.6 消息总线 (MessageTool)

基于发布/订阅模式的内部通信机制：

- 内部命令：`EFrameCommand` (渲染帧/刷新RTree/静态休息)
- 外部事件：`EOutEventCommand` (输入变更/画布参数变更/操作变更)

## 4. 数据流

### 4.1 绘制流程

```
用户输入 (Pointer Event)
    ↓
EventsLoader 捕获并标准化
    ↓
D2FrameTool 判断是否为画布操作
    ↓ (否则传递)
DrawD2ToolManager 路由到具体绘制工具
    ↓
创建/更新 Model (D2xxxModelManager)
    ↓
创建/更新 Shape (D2xxxShapeManager)
    ↓
RtreeService 更新空间索引
    ↓
MessageBus 发布 RENDER_FRAME
    ↓
Engine 重新渲染
```

### 4.2 选取流程

```
用户点击 (Pointer Event)
    ↓
EventsLoader → SelectionTool
    ↓
坐标转换: DOM → 场景物理坐标
    ↓
RTree.search(clickBBox) → 候选图元列表
    ↓
精确碰撞检测 (isPointOnStrokeLine / isPointOnStrokeArc...)
    ↓
SelectManager 更新选区
    ↓
HandlerControl 显示操控点
```

## 5. 坐标系统

| 坐标系 | 原点 | Y 轴方向 | 用途 |
|--------|------|---------|------|
| DOM 像素坐标 | canvas 左上角 | 向下为正 | 事件输入 |
| 场景物理坐标 | 世界原点 | 向上为正 | 数据存储 & 几何计算 |
| WebGL NDC | 视口中心 | 向上为正 | GPU 渲染 |

转换路径：`DOM → Camera.inverse → 场景` / `场景 → Camera.viewMatrix → NDC`

## 6. 图层系统

- **DrawLayer**：可视化图层容器
- **MaskLayer**：遮罩/控制层
- **DrawLayerModel** / **DrawLayerShape**：图层的数据与渲染分离
- **DrawLayerController**：对外操作接口

## 9. 设计模式应用

| 模式 | 应用位置 | 说明 |
|------|---------|------|
| 单例 | Manager 层, Camera | `getInstance()` / `quit()` 生命周期管理 |
| 发布/订阅 | MessageTool | 内部解耦通信 |
| 命令 | HistoryManager | Undo/Redo 实现 |
| 策略 | DrawD2ToolManager | 可切换的绘制工具 |
| 工厂 | ModelManager / ShapeManager | 图元的创建与管理 |
| 模板方法 | Scene, Primitive | 抽象基类定义流程 |
| 组合 | Polyline | 由 Primitive[] 组合而成的复合图元 |
| 观察者 | EventsLoader + InputInfo | 事件监听与分发 |
