## 1. 线性代数基础

### 1.1 Vector2

文件：`src/engine/algorithm/geometry/vector/Vector2.ts`

核心二维向量类，所有几何计算的基石。

#### 关键操作

| 方法 | 公式 | 用途 |
|------|------|------|
| `cross(v)` | x₁·y₂ − x₂·y₁ | 有向面积、旋转方向判定 |
| `dot(v)` | x₁·x₂ + y₁·y₂ | 投影计算、垂直判定 |
| `normalize()` | (x/‖v‖, y/‖v‖) | 单位化 |
| `rotate(θ)` | [cosθ, -sinθ; sinθ, cosθ]·v | 绕原点旋转 |
| `multiplyMatrix3(M)` | M·[x,y,1]ᵀ | 仿射变换 |
| `distance(v)` | √((x₂-x₁)² + (y₂-y₁)²) | 欧氏距离 |


#### 向量旋转公式

```
绕原点旋转 θ 弧度：
  x' = x·cos(θ) - y·sin(θ)
  y' = x·sin(θ) + y·cos(θ)

绕任意点 C 旋转 θ 弧度：
  dx = x - Cx,  dy = y - Cy
  x' = dx·cos(θ) - dy·sin(θ) + Cx
  y' = dx·sin(θ) + dy·cos(θ) + Cy
```

#### 向量平行与垂直判定

```
平行: |v₁ × v₂| ≤ ε  (叉积为零)
垂直: |v₁ · v₂| ≤ ε  (点积为零)
```

### 1.2 Matrix3

3×3 仿射变换矩阵，支持平移、缩放、旋转组合。数据按列主序存储于长度为 9 的 `Float64Array`。

### 1.3 Matrix4

4×4 齐次变换矩阵，用于相机视图/投影变换。支持正射投影 (Ortho) 和透视投影 (Perspective)。

## 2. 几何图元体系

### 2.1 继承结构

```
StructPrimitive<T>        (抽象基类，要求 multiplyMatrix3)
    │
    ├── Primitive          (抽象图元基类)
    │   ├── Line           (线段)
    │   └── Arc            (圆弧)
    │
    └── Polyline           (复合折线/曲线)

Triangle                   (三角形，独立类)
```


### 2.2 Line (线段)

文件：`src/algorithm/geometry/primitives/Line.ts`

#### 数据表示

- 起点 `startPoint: Vector2`
- 终点 `endPoint: Vector2`
- 一般式系数 `a, b, c`（惰性计算）：`ax + by + c = 0`

#### 一般式系数计算

```
a = endY - startY
b = startX - endX
c = endX·startY - startX·endY
```

#### 点到线段距离算法

使用参数化投影：
```
设 AB = end - start, AP = point - start
dot = AB·AP
lenSq = AB·AB
t = clamp(dot/lenSq, 0, 1)
D = start + t·AB
distance = |point - D|
```

### 2.3 Arc (圆弧)

文件：`src/algorithm/geometry/primitives/Arc.ts`

#### 数据表示

- 半径 `radius`
- 圆心 `centerPoint: Vector2`
- 起始弧度 `startRadian`
- 终止弧度 `endRadian`
- 扫掠方向 `sweep: CCW | CW`

#### 圆弧离散采样算法

基于弦高误差控制：

```
误差公式: e = r(1 - cos(θ/2))
解得步进角度: θ = 2·acos((r - e)/r)
采样段数: n = max(2, ceil(|sweepRadian| / θ))
```

此方法确保折线逼近与圆弧的最大弦高误差不超过指定的 `resolution` 值。


#### 圆弧 AABB 包围盒算法

```
算法步骤:
1. 用圆弧起点和终点初始化 bbox 边界
2. 规范化起始弧度到 [0, 2π)
3. 枚举四个轴对齐候选弧度: 0, π/2, π, 3π/2
4. 对每个候选弧度，判断其是否落在圆弧扫掠范围内
5. 若落入则用该方向极值点(cx±r 或 cy±r)扩展 bbox

弧度范围判定（CCW 情况）:
  offset = candidate - normStart
  if offset < 0: offset += 2π
  return offset ≤ sweepRadian
```

#### SVG 终点修正算法

当圆弧起点与终点距离 < 0.0002 时（近整圆场景），SVG 渲染器无法正确绘制。使用指数退避策略回退终点弧度：

```
step = sweep≥0 ? -0.01 : 0.01
while distance(start, end) < 0.0002:
    step *= 2
    endRadian += step
    endPoint = pointOn(endRadian)
```

### 2.4 Polyline (复合折线)

文件：`src/algorithm/geometry/primitives/Polyline.ts`

由 `Primitive[]`（Line/Arc 混合序列）组成的复合曲线。

#### 有向面积计算 (Shoelace 公式)

```
Area = Σ (x_i + x_{i+1}) · (y_{i+1} - y_i) / 2
```

正值表示逆时针，负值表示顺时针。用于判断多边形绕向。

#### 闭合判定

当 `primitives[0].startPoint == primitives[last].endPoint` 时认定为闭合。

### 2.5 Triangle (三角形)

文件：`src/algorithm/geometry/primitives/Triangle.ts`

#### 重心 (Barycenter)

```
G = ((x₁+x₂+x₃)/3, (y₁+y₂+y₃)/3)
```

#### 内心 (Incenter)

```
设三边长 a=|BC|, b=|AC|, c=|AB|
I = (a·A + b·B + c·C) / (a+b+c)
```

#### 面积 (叉积法)

```
Area = |AB × BC| / 2
```

## 3. 计算几何算法


### 3.1 点到直线垂足 (D2LineToolkit.calcFootOfPoint2Line)

文件：`src/algorithm/geometry/D2LineToolkit.ts`

#### 算法原理

已知直线一般式 `ax + by + c = 0`，点 P(px, py) 到直线的垂足 F(xf, yf)：

```
xf = (b²·px - a·b·py - a·c) / (a² + b²)
yf = (-a·b·px + a²·py - b·c) / (a² + b²)

参数 t = ((P-A)·(B-A)) / |B-A|²
  t < 0: 垂足在 A 外侧
  t > 1: 垂足在 B 外侧
  0 ≤ t ≤ 1: 垂足在线段上
```

### 3.2 线段交点检测 (D2LineToolkit.isSegmentIntered)

#### 跨立试验 + 参数方程法

```
Step 1: Orient 函数
  orient(A,B,C) = (B-A) × (C-A)  // 有向面积×2

Step 2: 跨立判定
  d1 = orient(A1, B1, A2)
  d2 = orient(A1, B1, B2)
  d3 = orient(A2, B2, A1)
  d4 = orient(A2, B2, B1)
  若 d1·d2 < 0 且 d3·d4 < 0 → 一般相交

Step 3: 交点计算
  R = B₁ - A₁
  S = B₂ - A₂
  t = (A₂-A₁) × S / (R × S)
  P = A₁ + t·R
```

### 3.3 点在有宽线段内检测 (D2LineToolkit.isPointOnStrokeLine)

#### 算法思路

1. 计算点到线段方向的投影向量
2. 计算垂直距离是否在 strokeWidth/2 范围内
3. 检查投影是否在线段长度范围内
4. 对 Round 端点追加半圆检测
5. 对 rectBorderRadius > 0 追加圆角矩形检测

### 3.4 线段上指定距离点计算 (D2LineToolkit.getPointsOnLineWithDistance)

#### 圆与线段求交

将线段参数方程代入圆方程：

```
线段: P(t) = start + t·(end-start), t∈[0,1]
圆: (x-Ox)² + (y-Oy)² = r²

代入得: At² + Bt + C = 0
  A = |end-start|²
  B = 2·(end-start)·(start-O)
  C = |start-O|² - r²
  Δ = B² - 4AC

Δ < 0: 无交点
Δ = 0: 相切, t = -B/(2A)
Δ > 0: 两交点, t = (-B±√Δ)/(2A)
```

仅保留 t∈[0,1] 范围内的有效解。

### 3.5 点在线段范围内检测 (D2LineToolkit.isInLineArea)

支持三种线帽模式：
- **BUTT**：t∈[0,1] 严格裁剪
- **ROUND**：t 超出时 clamp 到端点，用端点圆判定
- **SQUARE**：t 范围向两端各扩展 r/len


### 3.6 线段-圆弧交点 (D2Intersection.getIntersectionsOfLineAndArc)

文件：`src/algorithm/geometry/D2Intersection.ts`

#### 算法流程

```
1. BBox 快速排除: 线段 bbox ∩ 圆弧 bbox = ∅ → 无交点
2. 判断线段两端点与圆的位置关系:
   - state = 圆心到端点距离² 与 r² 的比较 (-1内, 0上, 1外)
3. 分情况处理:
   a. 两端点都在圆内 → 无交点
   b. 两端点都在圆上 → 两端点即为交点
   c. 两端点都在圆外 → 垂足法+距离判定
   d. 一内一外 → 参数方程求交
   e. 一端点在圆上 → 该端点+可能的第二交点
4. 过滤: 验证交点确实在圆弧弧段上 (isPointOnArc)
```

### 3.7 圆弧-圆弧交点 (D2Intersection.getIntersectionsOfArcs)

#### 算法分支

| 条件 | 处理 |
|------|------|
| d > R₁+R₂ | 外离，无交点 |
| d < \|R₁-R₂\| | 内含，无交点 |
| d = R₁+R₂ | 外切，圆心连线与两弧求交 |
| d = \|R₁-R₂\| | 内切，比例插值求切点 |
| 其他 | 构造公共弦垂线，解方程求交 |

公共弦方法：
```
δ = (d² - R₂² + R₁²) / (2d)
比例 pro = δ/d
公共弦中点: M = A₁ + pro·(A₂-A₁)
构造过 M 的垂线段
在垂线上用"线段-圆距离法"找到两个交点
验证两点均在两段弧上
```

### 3.8 点在圆弧上判定 (D2ArcToolkit.isPointOnArc)

#### 叉积判向法

```
向量定义:
  S = arcStart - center  (起点方向)
  E = arcEnd - center    (终点方向)
  P = point - center     (待测点方向)

叉积:
  crossSP = S × P  (P 相对于 S 的方位)
  crossPE = P × E  (E 相对于 P 的方位)
  crossSE = S × E  (E 相对于 S 的方位)

CCW 小弧: crossSP ≥ 0 且 crossPE ≥ 0
CCW 大弧: !(crossSP < 0 且 crossPE < 0)
CW 对称处理
```

### 3.9 三点定圆 (D2CircleToolkit.calculateCircleProfileByByThreePoint)

```
给定三点 P₁, P₂, P₃:
G = (x₂-x₁)(y₃-y₁) - (x₃-x₁)(y₂-y₁)  // 两倍有向面积
若 G = 0: 三点共线，无法确定圆

圆心:
  Cx = [(x₁²+y₁²)(y₂-y₃) + (x₂²+y₂²)(y₃-y₁) + (x₃²+y₃²)(y₁-y₂)] / (2G)
  Cy = [(x₁²+y₁²)(x₃-x₂) + (x₂²+y₂²)(x₁-x₃) + (x₃²+y₃²)(x₂-x₁)] / (2G)

半径: r = |C - P₁|
旋转方向: G>0 → CW, G<0 → CCW
```


### 3.10 向量投影计算 (D2LineToolkit.calculateVectorProjection)

```
已知: 线段方向向量 L, 位移向量 A
目标: 求 A 在 L 的垂线方向上的分量

垂线 B = normalize((-Ly, Lx))
投影 C = ((A·B)/(B·B)) · B
```

### 3.11 BBox2 包围盒创建 (BBox2Creator)

针对不同图元类型提供快速包围盒生成：

| 图元 | 包围盒算法 |
|------|-----------|
| Line | min/max(端点坐标) ± strokeWidth/2 |
| Circle | center ± (radius + strokeWidth/2) |
| Point | center ± radius |
| Arc | center ± (radius + strokeWidth/2) |
| Image/Rect/Text | 四角坐标取 min/max |

## 4. 三角剖分算法

### 4.1 Earcut 算法

文件：`src/algorithm/geometry/earcut/Earcut.ts`

基于链表的耳切法多边形三角剖分，支持带孔多边形。

#### 核心流程

```
1. 将多边形顶点构建为双向循环链表
2. 若存在孔洞，通过 eliminateHoles 将孔洞与外轮廓桥接
3. 大多边形(>80点)启用 Z-order 空间索引加速
4. 迭代查找"耳朵"三角形:
   - 三个相邻点 prev, curr, next
   - 若 orient(prev,curr,next) 为凸方向
   - 且三角形内无其他顶点
   - 则裁剪该耳朵，输出三角形索引
5. 重复直到多边形退化为三角形
```

时间复杂度：O(n²)（最坏），实际接近 O(n)。

### 4.2 Monotone Triangulation (单调多边形三角剖分)

文件：`src/engine/algorithm/monotoneTriangulates/MonotoneTriangulates.ts`

基于扫描线的 CDT (Constrained Delaunay Triangulation) 实现。

#### 核心数据结构

- **Event**：扫描事件（POINT/START/END）
- **PartialHull**：部分凸包，维护上/下边界索引列表

#### 算法流程

```
1. 构建事件列表:
   - 每个顶点 → POINT 事件
   - 每条约束边 → START 事件(左端) + END 事件(右端)

2. 事件排序:
   - 按 x 坐标升序
   - 同 x 按 y 坐标
   - 同坐标按事件类型 (POINT < END < START)
   - 同类型按绕向 (CCW)

3. 扫描处理:
   - POINT: 对所有 hull 执行凸包增量更新
     - 检查上边界/下边界是否可以形成新三角形
     - orient 判定: 上边界逆时针出三角形，下边界顺时针出三角形
   - START: 在 hulls 中分裂(split)，插入新的 PartialHull
   - END: 合并(merge)相邻 PartialHull

4. 输出: 所有生成的三角形索引
```

## 5. 空间索引 R-Tree

文件：`src/algorithm/rtree2/Rtree.ts`

### 5.1 概述

R-Tree 是一种平衡树结构，用于高效的空间范围查询。本实现为 2D 矩形索引，最小子节点数 = width/2，最大子节点数 = width。

### 5.2 数据结构

```typescript
type TRtreeNodeItem = {
    x: number      // 包围矩形左下角 x
    y: number      // 包围矩形左下角 y
    w: number      // 宽度
    h: number      // 高度
    nodes: Array<TRtreeNodeItem>  // 子节点
    leaf?: any     // 叶节点存储的数据对象
    id?: string
}
```

### 5.3 核心操作

| 操作 | 文件 | 时间复杂度 |
|------|------|-----------|
| 插入 | `insertSubtree.ts` | O(log n) |
| 删除 | `removeSubtree.ts` | O(log n) |
| 范围查询 | `searchSubtree.ts` | O(log n + k) |
| 选择子树 | `chooseLeafSubtree.ts` | O(M) per level |
| 分裂 | `linearSplit.ts` | O(M) |

### 5.4 插入策略

1. 从根节点开始，选择面积增量最小的子节点路径
2. 在叶节点层插入新矩形
3. 若节点溢出 (children > maxWidth)，执行线性分裂
4. 分裂后向上传播更新父节点包围矩形

### 5.5 线性分裂

选取两个"种子"节点（距离最远的一对），将剩余节点逐个分配到面积增量更小的组。

### 5.6 范围查询

递归遍历树节点，仅进入与查询矩形相交的子树，收集所有满足条件的叶节点。

## 6. 红黑树

文件：`src/engine/algorithm/RBTree/RBTree.ts`

### 6.1 概述

持久化（函数式）红黑树实现，插入/删除操作返回新树根而不修改原树。用于扫描线算法中的有序事件管理。

### 6.2 性质

1. 节点为红或黑
2. 根节点为黑
3. 红节点的子节点为黑
4. 从根到叶的路径中黑节点数相同
5. 所有操作保持 O(log n) 时间复杂度

### 6.3 核心操作

| 操作 | 说明 |
|------|------|
| `insert(key, value)` | 插入并执行旋转/重着色平衡 |
| `remove(key)` | 删除并修复双黑缺陷 |
| `find(key)` | 精确查找，返回迭代器 |
| `ge/gt/lt/le(key)` | 范围查找，返回迭代器 |
| `forEach(visit, lo?, hi?)` | 中序遍历(可指定范围) |

### 6.4 迭代器 (RedBlackTreeIterator)

通过维护从根到当前节点的路径栈实现 O(1) 均摊的 `next()`/`prev()` 遍历。

## 7. 相机与投影变换

文件：`src/engine/common/Camera.ts`

### 7.1 正射投影矩阵

```
Ortho(l, r, b, t, n, f):
┌ 2/(r-l)    0        0       -(r+l)/(r-l) ┐
│   0      2/(t-b)    0       -(t+b)/(t-b) │
│   0        0      -2/(f-n)  -(f+n)/(f-n) │
└   0        0        0             1       ┘
```

正射投影参数由 canvas 尺寸确定：
- left = -width/2, right = width/2
- bottom = -height/2, top = height/2

### 7.2 LookAt 视图矩阵

```
eye = (ex, ey, 0.1)  // 相机位置
at  = (ex, ey, 0)    // 观察目标
up  = (0, 1, 0)      // 上方向

视图矩阵 = LookAt(eye, at, up)
```

### 7.3 最终变换矩阵

```
ViewMatrix = LookAt × Projection × Scale

其中 Scale 由用户缩放操作控制 (scaleRatio)
```

### 7.4 坐标转换流程

```
DOM 像素坐标 (左上角原点, Y 向下)
    ↓ 翻转 Y + 偏移至中心
场景物理坐标 (世界原点, Y 向上)
    ↓ × ViewMatrix
WebGL NDC [-1,1]
```

```
rad2deg(r): 弧度 → 角度
deg2rad(d): 角度 → 弧度
```

### 9.4 Calculation (通用计算)

向量运算、数值范围约束等通用数学函数。

### 9.5 NDArray (N 维数组)

多维数据容器，用于矩阵运算中间结果存储。

## 10. WebGL 渲染算法

### 10.1 缓冲区管理

- **ARRAY_BUFFER**：顶点属性数据 (位置/颜色/UV)
- **ELEMENT_ARRAY_BUFFER**：索引数据
- 支持 `STATIC_DRAW` 和 `DYNAMIC_DRAW` 两种使用模式

### 10.2 实例化渲染

通过 `ANGLE_instanced_arrays` 扩展实现同一图元的批量渲染：
- 共享几何数据（顶点/索引）
- 每个实例独立的变换矩阵和颜色参数
- 单次 DrawCall 渲染大量相同类型图元

### 10.3 混合模式

2D 模式下的标准 Alpha 混合：
```
gl.blendFunc(SRC_ALPHA, ONE_MINUS_SRC_ALPHA)
```

关闭深度测试、面剔除，启用多边形偏移。

### 10.4 帧缓冲离屏渲染

支持帧缓冲栈式管理，用于后处理效果和纹理生成：
```
enterfb(fb) → 渲染到纹理 → leavefb() → 恢复上一级帧缓冲
```

## 11. 算法复杂度总结

| 算法 | 时间复杂度 | 空间复杂度 |
|------|-----------|-----------|
| 点到线段距离 | O(1) | O(1) |
| 线段交点 | O(1) | O(1) |
| 点在圆弧上 | O(1) | O(1) |
| 圆弧离散采样 | O(n) n=段数 | O(n) |
| 三点定圆 | O(1) | O(1) |
| Earcut 三角剖分 | O(n²) worst | O(n) |
| Monotone 三角剖分 | O(n log n) | O(n) |
| R-Tree 查询 | O(log n + k) | O(n) |
| R-Tree 插入 | O(log n) | O(n) |
| 红黑树操作 | O(log n) | O(n) |
| BBox 包围盒 | O(1) per elem | O(1) |
